Claudeの始め方

インストールでつまずいた私が、1か月でやってきたこと。

村田亜衣（マネージャー）

私はエンジニアではありません。柔術道場のマネージャーで、その前は大学職員でした。Claude Code を入れようとしたときは、インストールの時点でつまずいて、しばらくは普通のチャットで質問するだけでした。

それが1か月ちょっとたった今では、請求書や振込リストの事務作業、大会のライブ速報、動画やデザインづくり、そしてこのサイトのページまで、Claude と一緒にやっています。

このページは、講座のような「正しい教え方」ではありません。私が実際に通ってきた順番と、つまずいたところをそのまま並べました。これから始める方の、ひとつの道しるべになればうれしいです。

まず知っておくことCHAT・COWORK・CODE

Claude には大きく3つの使い方があります。どれも同じ Claude ですが、得意なことが少しずつ違います。私はこう覚えています。

答えがほしいなら Chat。ファイルがほしいなら Cowork。
仕組みがほしいなら Code。

答えがほしいChat

話しかけて答えてもらう。スマホからでもすぐ使える、いちばん身近な入り口です。

LINEの返信、この言い方で失礼じゃないかな？

ファイルがほしいCowork

パソコンのフォルダを渡して、書類づくりや整理をまるごとお願いする。

このフォルダの領収書から、日付と金額の一覧表を作って

仕組みがほしいCode

道具そのものを作る。一度作れば、次からは一言で、または自動で回ります。

毎月の請求書の手順を覚えて、来月は「今月もお願い」で済むようにして

きっちり分けなくても大丈夫です。Chat で相談しているうちに「これ毎月やるな」と気づいたら、Code に持っていけばいい。私は結局、Code を開いている時間がいちばん長いです。

始める順番7 STEPS

いきなり全部やろうとしなくて大丈夫です。私はだいたいこの順番で、できることが増えていきました。

  1. まずは Chat で、何か1つ聞いてみる

    いちばん気軽なのはスマホのアプリです。仕事の相談でも、LINE の文面の確認でも、言葉の意味でも。相談相手・壁打ち相手として使うところから始めます。

    Claude Code のインストールでつまずいたあと、しばらくはずっとここにいました。遠回りのようで、「AIに話しかける」ことに慣れる時間になっていたと思います。

  2. Claude Code を入れる。つまずいたら、詳しい人に一度だけ付き合ってもらう

    パソコン（Mac か Windows）に Claude のデスクトップアプリを入れると、その中で Claude Code が使えます。最初の設定でよくわからない画面が出てきたら、ひとりで悩み続けないこと。

    私はここで止まっていました。動き出したのは、知り合いの濱田さんに5時間くらいつきっきりで教えてもらってから。最初の一歩だけは、人に手を引いてもらうのがいちばんの近道でした。

  3. 最初の1つは「しつこく」やりきる

    AIはけっこう「できません」と言ってきます。でも、たいていは言い方を変えればできます。

    AIは「できません」ってよく言ってくるけど、絶対できるから。しつこく「やって、やって」って戦うのがいいよ。― 濱田さん

    • 別の言い方で、もう一度頼む
    • 「じゃあ、別のやり方でできない？」と聞く
    • なぜそれがしたいのか、理由まで話す
    この言葉を信じて、最初の案件に5時間くらいかけて格闘しました。そうしたら本当にできて、終わるころには「あ、こういうふうに言えばいいんだ」というコツがつかめていました。1つやりきると、そこから先が一気に楽になります。 この話をブログで読む →

  4. 打たずに、しゃべる

    パソコンやスマホの音声入力で、思いついたことをそのまま話しかけます。「えーと」「まあ」が入っていても、言い間違えても大丈夫。AIが前後の流れからくみ取ってくれます。きれいな文章にしようとしないほうが、うまくいきます。

    体感で打つより5倍くらい速いです。しかもしゃべると「なぜそうしたいのか」まで自然に口から出るので、一発で思った通りのものが出てくることが増えました。「公開してください」を「紹介してください」と言い間違えても、ちゃんと公開してくれました。 この話をブログで読む →

  5. 手元のファイルを1つ渡してみる

    毎月使っている Excel や、たまったレシートの写真など、手元にあるものを1つ渡して「これを見て、〇〇して」と頼みます。最初の一回は、答えが合っているか自分でも確かめます。

    パーソナルレッスンの集計や、紙の領収書の読み取りから始めました。領収書は2団体分で432枚。スキャンして渡したら、日付・金額・用途の一覧になりました。 領収書のデジタル化 →

  6. 毎月やっている作業を1つ、「型」にする

    うまくいったら「今の手順を覚えておいて（スキルにして）」と頼みます。翌月からは「今月もお願い」の一言で、同じ手順が回るようになります。「毎月やっている」「何度も同じことをしている」と気づいたら、それが型にする合図です。

    請求書・振込リスト・勤怠の集計など、今は毎月の作業を6本、一言で回せる状態にしています。 道場での使い方をまとめたページ →

  7. 過去の分を、一度見直してもらう

    Claude は、たまった過去のデータを一気にさかのぼって見るのが得意です。ひとりで抱えてきた作業ほど、一度見てもらう価値があります。

    毎月ひとりで作ってきた業務委託の請求書を、1年分さかのぼって見てもらったら、自分では一生気づけなかった間違いが見つかりました。ぞっとすると同時に、「この相棒は本当に大事だ」と思った一日でした。 この話をブログで読む →

私がつまずいたことTROUBLES

始めてみると、だいたいどこかで止まります。私が実際に止まったところと、どうしたかです。

インストールアプリを入れるところから、よくわからない

私もまさにここで止まりました。ひとりで検索し続けるより、詳しい人に一度だけ横についてもらうほうが早いです。そのあいだは、スマホの Chat で「AIに話しかける」ことに慣れておけば、時間はむだになりません。

「できません」頼んだのに、できないと言われる

ここであきらめないのが、いちばん大事なところです。言い方を変える、別のやり方を聞く、目的を話す。「しつこく」が正解でした。何度かやりとりするうちに、通る頼み方がわかってきます。

画面自分が作業している最中に、画面が勝手に切り替わる

今いちばん困っているのがこれです。Claude に頼んでおいた作業が動き出して画面を使い始めると、私の作業とぶつかって、どちらも止まってしまいます。

今は、画面を使う作業は、ジムに行っているあいだや夜など、席を外すときにまとめてお願いするようにしています。

ことばGitHub や MCP など、知らない言葉が出てくる

GitHub（作ったものを保存・公開する場所）や MCP（AIとほかのサービスをつなぐ仕組み）は、私も今でもちょこちょこ人に相談しながら進めています。わからない言葉は、そのまま Claude に「これ何？ やさしく教えて」と聞けば大丈夫です。全部わかってから始める必要はありません。

会社会社の決まりで、仕事には使えない

大学職員だったので、この事情はよくわかります。会社やお客さまの情報を扱う以上、勝手には使えません。

だったら、暮らしのほうで試してみるのがおすすめです。私は4年分たまった料理教室の紙のレシピを、ひとつのサイトにまとめようとしています。規定が整ったときにすでに手に馴染んでいたら、きっと強いはずです。 この話をブログで読む →

最初の一言FIRST WORDS

専門用語はいりません。職場の人に頼むのと同じ言い方で大丈夫です。そのままコピーして使えます。

相談この返信、失礼じゃないか見て。もう少しやわらかい言い方の案も3つ出して。
ことばGitHubって何？ パソコンが得意じゃない人にもわかるように、たとえ話で教えて。
EXCELこのファイルを見て、今月の合計を出して。どう計算したかも書いて。
レシートこのレシートの写真、日付と金額と何の支払いかを表にして。
やること今日やること出して。締切が近いものから並べて。
型にする今やった手順、スキルにして。来月からは「今月もお願い」で同じことができるようにして。
見直しこのフォルダの請求書、1年分さかのぼって見て。計算が合わないところや、ほかの月と違うところを教えて。
「できません」できない理由を教えて。そのうえで、別のやり方で同じゴールにたどり着く方法を3つ出して。

私が決めている約束RULES

お金や人の情報を扱うようになったら、ここだけは最初に決めておくと安心です。

4 RULES

最後は、自分の目で全部見る

集計や突き合わせは Claude に任せる。できあがったものは、必ず自分で最後まで確認する。お金が動くところは特に慎重に。

送信・支払い・削除は、自分で押す

請求書の発行、振込、メッセージの送信は、Claude に直前まで準備してもらって止める。最後のボタンは人が押す。

パスワードは渡さない

ログインは自分でしておく。Claude にはログイン済みの画面を読んでもらうだけ。

人の名前は外に出さない

作ったものを公開するときは、会員さんやスタッフの名前を仮名にする。公開前に中身を目で確認する。

やりたいことの見つけ方IDEAS

一度コツがつかめると、「じゃあこれもできる？」が次々に出てきます。私はこんなところから見つけています。

画面を見ない時間に考える

ジムにいるときなど、携帯を触らない1時間に、「あれ面倒だな」「これなんとかならないかな」が浮かんできます。

「毎月やってる」に気づく

同じことを何度もしている、と気づいたら型にするチャンス。請求書、振込、シフト表はここから生まれました。

人の使い方を聞く

濱田さんとは会うたびに「今回こんなの作ったよ」と近況報告会。人の話を聞くと、「私の仕事ならこう使える」とまた湧いてきます。

昔の経験は、むだにならないFROM WORD PROCESSOR TO AI

ワープロ→HTML→Excel・PowerPoint→Word・Excel・PowerPoint→Claude

ひとりで始めるのが不安なら。
インストールから最初の一言まで、隣でいっしょに進めます。いまはYAWARA・SWEEPの会員さん限定で、事例として載せてよい方は無料です。AIのお手伝い、承ります →

小学生でワープロ、中学生でホームページ、大学で Excel に追いこまれ、大学職員で Office に熟練して、今は AI。振り返ると、道具が変わっても「新しいものを覚えて、仕事をちょっと楽にする」のが好きなのは同じでした。

ちがうのは、AI はこちらの言葉で頼めば、道具のほうが歩み寄ってくれるところです。そして、Excel や Word で「ここは手作業だと大変」と知っているからこそ、何を頼めばいいかがすぐに浮かびます。道具を覚えてきた時間は、今「頼み方」に生きています。

Claude は、難しい道具ではありません。「こういうことがしたい」があれば、どんどん形になります。まずはスマホで、ひとこと話しかけてみてください。
