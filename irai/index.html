「AIが便利なのは分かるけど、何から手をつければいいか分からない」。そう感じている方のそばで、私がやってきたことをそのままお手伝いします。

できることMENU

01

小さな道具を、作ります

「毎日つけている売上をスマホで入れたい」「Excelの集計を毎月手でやっている」。大きなシステムを入れるほどではない困りごとに合わせて、その仕事だけのための道具を作ります。

これまでの例：サロンの顧客管理・領収書のデジタル化・月次シフト表・大会の速報ページ

02

隣で、いっしょに始めます

Claude のインストールから、最初の「これをやって」まで。画面を見ながら、あなたの実際の仕事を題材にいっしょに進めます。講義ではなく、隣に座って手を動かすやり方です。

私の場合の順番：Claudeの始め方・柔術道場のClaude Code

03

毎月の作業を、仕組みにします

給与計算の準備、会費の入金確認、期限の見張り。決まった日に決まった手順で回っている仕事を、AIが自動で動かす「係」にします。最後の送信や支払いは、人が押す形のままです。

うちの場合：うちの会社に、AI社員が6人いた
