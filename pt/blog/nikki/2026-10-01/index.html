Como mostrar como exemplo uma ferramenta feita para um cliente

2026.10.01 (qui) Ai Murata (gerente)

O maior “hein?!” de hoje foi conseguir apresentar o sistema de reservas que fiz para um cliente como uma “demonstração que funciona”, sem tocar em nada do sistema real. Conto aqui os cuidados que tomei ao mostrar algo feito a pedido de alguém.

  1. Fazer uma “versão demo” desligada do sistema real

    Fiz uma página que apresenta como trabalho o sistema de inscrição do workshop que criei ontem. Ela conta o que foi pedido, mostra as telas, o que dá para fazer e como os dados pessoais são protegidos. Também preparei uma versão demo que funciona com dados de exemplo. Ela não está ligada ao recebimento real, então, mexa quem mexer, nenhuma inscrição de verdade entra.

    Se quiser copiar, peça assim

    Faça uma página de apresentação desta página de inscrição. Prepare também uma versão demo com dados de exemplo, sem ligar ao recebimento real

    DescobertaDa página de apresentação e da demo, tirei o nome e o logo de quem encomendou. A página real, usada pelos participantes, ficou como estava. O que se pode mostrar é diferente na versão para exibir e na versão para usar.

    Ver o resultado →

  2. Troquei a foto da tela, mas continuava a antiga

    Mesmo trocando as capturas de tela da apresentação, às vezes o navegador continua mostrando as antigas. Por isso, pedi para colocar um “número de versão” depois do nome da imagem, para o navegador saber que ela é nova.

    Se quiser copiar, peça assim

    Troquei a imagem, mas continua aparecendo a antiga. Faça a imagem nova aparecer sempre

    DescobertaNão é preciso mexer no arquivo da imagem: basta colocar o número no lugar que chama a imagem. Pelo jeito, é só aumentar o número em 1 a cada troca.

  3. Se não dá para mostrar o real, mostre um exemplo fictício

    O livro de receitas feito a partir das receitas em papel de uma aula de culinária ainda não foi publicado em lugar nenhum. Então, no portfólio, coloquei um livro de receitas fictício com 12 pratos caseiros. As fotos dos pratos foram geradas por IA, e o cartão também avisa “fotos geradas por IA”. O preço ainda não foi definido, então tirei também essa informação.

    Se quiser copiar, peça assim

    Faça uma versão de exemplo deste livro de receitas. Use 12 pratos caseiros fictícios, gere as fotos por IA e avise isso também

    DescobertaMesmo quando não dá para mostrar o real, um exemplo fictício já transmite “o que dá para fazer”. O que ainda não foi definido (como o preço) é melhor tirar também do exemplo, para não gerar mal-entendido.

    Ver o resultado →

Justamente o que é feito sob encomenda deixa a gente em dúvida sobre como mostrar. Pedindo “faça funcionar com dados de exemplo” e “tire o nome”, ficou em um formato que dá para apresentar com tranquilidade.
