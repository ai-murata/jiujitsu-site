I stopped typing and started talking: when to use Chat, Cowork, and Code

2026.09.27 · Ai Murata (Manager)

Hi, this is Ai Murata. For my second post, I'll talk about two things in how I've been using Claude lately: voice input, and choosing between Claude's 3 options.

I stopped typing and started talking

I used to type my requests to Claude Code on the keyboard. But lately I've gotten completely hooked on voice input.

It feels about 5 times faster than typing. I just say whatever comes to mind, so my hands never stall while I wonder how to phrase something.

Even when you misspeak, it gets through

Voice input makes a fair number of conversion errors and slips. But AI picks up the meaning from the flow around them, so it's rarely a problem. These actually happened while I was making this very blog. (The mix-ups come from similar-sounding Japanese words.)

  • "Please introduce it" (shokai shite)→ What I really said was "Please publish it" (kokai shite). It published it just fine
  • "An idea in Japan came to me" (nihon de)→ What I really said was "an idea for a second post" (nihon-me). It became this second post just fine

It's fine if your "um"s and "well"s stay in. It actually works better if you don't try to make your sentences neat.

When you talk, more information gets through

I noticed something else, too: when you talk, you naturally explain why you want something. When I type, I tend to keep it short, just "do X." When I talk, the background and my feelings come out as well. That makes it easier for AI to get what I'm after, and more often I get what I wanted on the first try.

Claude's 3 options

The other fun thing lately has been choosing how to use Claude. Broadly speaking, there are 3 ways to use it: Chat, Cowork, and Claude Code. They're all the same Claude, but each is good at slightly different things.

To sort out the differences, I think this is the easiest way to remember them.

Want an answer? Chat.
Want a file? Cowork.
Want a system? Code.

Want an answerChatAdvice, questions, draft writing
Want a fileCoworkMaking and organizing documents on your computer
Want a systemCodeReusable tools, sites, automation

Chat: when you want an answer right now

This is the most familiar way to use it: you talk, it answers. You can use it right from your phone too. It's perfect as someone to consult or bounce ideas off when you want to sort out your thoughts.

For example

  • Does this LINE reply sound rude?
  • Make this tournament announcement a little easier to understand
  • What does this wording in the contract mean?

But Chat is basically "answer on the spot and done." Any files it makes for you, you have to download and put in a folder yourself.

Cowork: when you want it finished as a file

To be honest, I haven't used Cowork much yet. So this part is more of an intro: "apparently it's good for situations like this."

With Cowork, you hand over a folder on your computer and give it the whole job. Claude reads what's in the folder and saves the finished documents into that folder. Once you've asked, you can go do something else for a while.

For example

  • Make a table of dates and amounts from the receipt photos in this folder
  • Sort this messy folder by what's inside
  • Read all of these materials and sum them up on one page for the meeting

For something that's a one-time job but that you really do want as a file, Cowork is a good fit.

Claude Code: when you want a reusable system

Claude Code is for making the tool itself. Build it once, and from then on the same thing runs automatically or with a single line. The word "Code" in the name makes it sound hard, but all you're really doing is saying "I want something like this."

For example

  • Learn the steps for my monthly invoices, so from next month I can just say "this month too, please"
  • Automatically collect the tournament results and post them on a live results page
  • Make this blog or site page and publish it

When you notice "I do this every month" or "I keep doing the same thing," that's when Claude Code comes in.

If you're not sure, any of them is fine

That said, you don't need to keep them strictly separate. If you're talking something over in Chat and realize "I'll be doing this every month," take it to Claude Code. If you like a document you made in Cowork, ask, "Turn this into a system that makes it every month."

As for me, I've come to love building systems so much that Claude Code is where I end up spending the most time. And lately, I just sit there talking at it.

Start with voice input, and try telling Claude whatever comes to mind. I think you'll find it easier to get going than typing.
