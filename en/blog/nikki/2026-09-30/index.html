The day I connected a booking page to Google Sheets

2026.09.30 (Wed) Ai Murata (Manager)

Today’s biggest “Wait, what?” was connecting an event’s workshop booking page to Google “Apps Script” (small programs that run behind a spreadsheet), so people can sign up while seeing what’s open. I hit a few snags getting it connected.

  1. Letting Google run the front desk for a booking page

    I made a sign-up page for an event workshop and put Google's Apps Script in charge of taking the sign-ups. Customers can pick a date and time while seeing what's still open, and they can cancel from the same page. I was amazed that you can build a whole booking system without renting a server.

    If you want to copy this, ask like this

    Make a sign-up page for [event]. Use Google Apps Script to record sign-ups in a spreadsheet, and let people see what's still available

    Discovery At first the page wouldn't load and I couldn't tell why. I had Claude change it so the screen shows the cause when Google's sharing setting isn't "Anyone" or when the URL is wrong.

  2. Deleting a "required field" from the page isn't enough

    The sign-up didn't need an address field, so I had Claude remove it from the page. But the front-desk side had already gone live with the address still set as required. So the page now sends "—" in place of an address, and the next version of the front desk accepts sign-ups with the address left empty.

    If you want to copy this, ask like this

    Remove the address field from this sign-up page. Also check that it isn't required on the receiving side

    Discovery When you cut a form field, you have to fix both the page people see and the side that receives the data behind the scenes. Rebuilding the front desk changes its public URL, so don't forget to swap that in too.

  3. Updating a tournament schedule over and over in one night

    I made a match schedule page for the Reversal Jiu-Jitsu Cup Sapporo 2026. Every time new information came in, it got updated, many times over the course of the night. I also added it to the tournament list page.

    If you want to copy this, ask like this

    Make a match schedule page for the [name] tournament. Whenever I send new information, add it each time

    Discovery Once the page exists, all you have to do is send new information and it gets updated. In the rush before a tournament, it was a huge help not to have to fix the page myself.

When you get stuck, I recommend asking, "Make it show on screen why it isn't working." Once you can see the cause, you won't panic next time.
