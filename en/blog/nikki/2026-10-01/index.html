How to show off a tool you built for someone else

2026.10.01 (Thu) Ai Murata (Manager)

Today’s biggest “Wait, what?” was that I could present a booking system I built for a client as a “working sample,” without touching the real thing at all. Here’s what I was careful about when showing something I made at someone’s request.

  1. Making a demo that isn't connected to the real thing

    I made a page presenting yesterday's workshop sign-up system as a portfolio piece. It covers what I was asked for, what the screens look like, what it can do, and how it protects personal information. I also set up a demo version that runs on sample data. The demo isn't connected to the real front desk, so no matter who plays with it, no real sign-ups come in.

    If you want to copy this, ask like this

    Make a page presenting this sign-up page. Also set up a demo version that runs on sample data, and don't connect it to the real sign-up system

    Discovery I took the client's name and logo off the presentation page and the demo. The real sign-up page that participants use stays as it is. What's okay to show differs between the version for showing and the version for using.

  2. I replaced the screenshot, but the old one still shows

    Even after you update a screenshot, the browser can keep showing the old one. So I had Claude add a "version number" after the image's name, so the browser knows it's a new image.

    If you want to copy this, ask like this

    I replaced the image but the old one keeps showing, so make sure the new one always appears

    Discovery You don't touch the image file itself. Just adding a number on the side that calls up the image fixes it. Apparently you only need to raise the number by 1 each time you replace it.

  3. If you can't show the real thing, show a dummy

    The recipe book I made from a cooking class's paper recipes hasn't been released anywhere yet. So for my portfolio I put in a dummy recipe book with 12 home-style dishes. The food photos were made with AI, and the card says so: "Photos were created by AI." The price isn't decided yet, so I took that off too.

    If you want to copy this, ask like this

    Make a sample version of this recipe book. Fill it with 12 made-up home-style dishes, make the photos with AI, and say so on it

    Discovery Even when you can't show the real thing, a dummy still gets across what can be made. Leave undecided things (like price) out of the sample too, and nobody gets the wrong idea.

The more something is client work, the harder it is to know how to show it. By asking "run it on sample data" and "take the name off," I got versions I could present with peace of mind.
