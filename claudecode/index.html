柔術道場のClaude Code

道場の裏方仕事を、AIに任せてきた記録。

会費の集計、請求書、シフト表、大会の速報、動画の字幕。道場の運営には、マットの外の仕事がたくさんあります。 Claude Code は、話しかけるだけでパソコンの中の作業をやってくれるAIです。 私たちが実際に使ってきた内容を、白帯から黒帯までの段階に並べました。このサイトのページも、すべて Claude Code で作っています。

できることWHAT IT DOES

チャットで答えるだけのAIとの違いは、手を動かすところまでやってくれることです。

ファイルを読んで、作るExcel・PDF・写真・動画を開いて中身を読み、集計表や書類を新しく作ってフォルダに置きます。
ウェブを見に行く予約システムや大会の結果ページを読み取って、必要な数字だけを抜き出します。
手順を覚えておく毎月の作業の手順を「スキル」として保存すると、次の月は「今月もお願い」の一言で同じ手順を回せます。
最後は人が押す送信・支払い・削除の手前で止まって確認してくれます。任せきりにならない作りです。

帯ごとの使い方BELTS

いきなり黒帯の技はかかりません。白帯から順に、できることを増やしていくのがおすすめです。

WHITE白帯

聞く・書かせる

文章の相談相手として。入れた初日からできます。

  • お知らせ文の下書き　休館日、月謝の改定、大会エントリーの締切案内

  • 海外の先生とのやりとり　ポルトガル語・英語のメッセージを訳して、返事も作る
BLUE青帯

Excelと紙を片付ける

手元のファイルを渡して、集計と清書を任せます。

  • パーソナルレッスンの集計　担当インストラクター別の回数・単価・歩合を月ごとにまとめる
  • 領収書の読み取り　紙の束をスキャンして渡すと、日付・金額・用途の一覧になる実例 →
  • 大会・イベントの収支表　チケットの販売明細と経費を突き合わせて、A4一枚の報告書に
  • 契約書のひな形　業務委託や協賛の契約書を、前回の条件から作り直す
PURPLE紫帯

予約システムとつなぐ

会員管理の画面を読みに行かせて、人がやると半日かかる抽出を任せます。

  • 月会費の未払いチェック　引き落としに失敗した人だけを拾い、入会したばかりの人は除いて一覧に
  • 勤怠と歩合の集計　打刻データとクラスの担当実績から、給与計算用の表を作る
  • 請求書・領収書の下書き　請求書サービスに下書きまで入れて、発行ボタンは人が押す
  • 予定との突き合わせ　共有カレンダーと経費を照らして、どの遠征の支出かを特定する
BROWN茶帯

毎月の型にする

うまくいった手順を「スキル」として残し、決まった日に自動で走らせます。

  • 月次の定型作業をスキルに　請求書・振込リスト・勤怠を「今月の分お願い」の一言で回す
  • 決まった日に自動で　毎月25日に未払いチェックを走らせ、結果をフォルダに置いておく
  • シフト表をスマホで　Excelのシフトを、スタッフがスマホで見られるページに実例 →
  • 補助金を毎日チェック　道場が使える補助金の一覧を、毎朝自動で更新実例 →
BLACK黒帯

道場の道具を自分で作る

市販のサービスにない、柔術ならではの道具を作ってしまう段階です。

  • 大会のライブ速報　トーナメント表から自分の道場の選手だけを追い、試合順と結果を自動で更新実例 →
  • 全国の道場ガイド　2つの連盟の加盟道場を集めて、地域で探せる検索サイトに実例 →
  • はじめての大会ガイド　初出場の会員さんに渡す、当日の流れとマナーのページ実例 →
  • 減量の記録帳　計量日から逆算して、1日500gまでの落とし方を選手ごとに管理
  • 動画の字幕と写真選び　試合動画の文字起こしから字幕を作り、大会写真を時間帯ごとに満遍なく選ぶ

毎日の使い方EVERY DAY

月に一度の大仕事より、毎日の細かい用事で使うことのほうが多いです。ある一日の流れです。

  1. 9:00今日やることが届いているカレンダー・メール・作業中のフォルダを自動で見て、今日の「やること一覧」を朝のうちに作っておいてくれる。
  2. 午前メールと問い合わせ体験の申込み、大会エントリーの質問、協賛の相談。中身を読んで返信の下書きまで作り、送るのは自分。
  3. 午前会員さんの確認「◯◯さんの回数券、あと何回？」「今月入会した人は？」を予約システムから調べて答える。
  4. 昼インストラクターからの相談シフトの入れ替え、パーソナルの空き枠、代行の手配。表を見て、空いている人と時間を出す。
  5. 午後SNSと制作物大会写真から投稿用を選ぶ、リール動画に字幕を付ける、チラシやTシャツを印刷会社の仕様で書き出す。
  6. 夕方お金まわりその日のレシートを渡して整理、頼まれた領収書を発行の手前まで準備、経費の科目を確認。
  7. 夜席を外している間に画面を使う作業は昼にやらず、留守の間にまとめて片付けてもらう。大会の週末は、試合の結果が出るたびに速報ページを更新。

こう頼めば動くHOW TO ASK

専門用語はいりません。道場のスタッフに頼むのと同じ言い方で大丈夫です。

朝今日やること出して。締切が近いものから並べて。
問い合わせこの体験の問い合わせに返信の下書きを作って。持ち物と、道着を貸せることも書いて。
会員◯◯さんの回数券、あと何回残ってる？期限もあわせて教えて。
シフト来週火曜の夜クラス、代わりに入れるインストラクターは誰？
写真この大会の写真から、インスタ用に10枚選んで。いろんな選手が入るように。
会費今月の月会費、引き落としに失敗した人を一覧にして。入会したばかりの人は除いて。
大会この大会のトーナメント表から、うちの道場の選手の試合だけ時間順に並べて。
経費このレシートの写真、日付と金額と何の支払いかを表にして。カード控えと二重になってるものは外して。
動画この試合動画に日本語字幕をつけて。選手の名前は大会の登録名に合わせて。
減量計量まであと3週間で4kg落としたい。水抜きなしで、1日500gを超えない計画を作って。
定型化今やった未払いチェックの手順、スキルにして毎月25日に自動で回るようにして。
契約書この協賛契約書、去年のものと条件が変わったところだけ教えて。

道場で使うときの約束RULES

会員さんのお金と個人情報を扱うので、ここだけは最初に決めておきます。

4 RULES

送信・支払い・削除は人が押す

請求書の発行、振込、メッセージの送信は、Claude が直前まで準備して止まる。最後のボタンはスタッフが押す。

会員の名前は外に出さない

シフト表や速報ページを公開するときは、スタッフや会員の名前を仮名にする。公開前に中身を目で確認する。

パスワードは渡さない

ログインはスタッフ本人がしておく。Claude はログイン済みの画面を読むだけ。

置き場所を1つに決める

作ったファイルは共有フォルダの「年月＋案件名」に置く。デスクトップに散らからないようにする。

はじめ方START

パソコンが得意な人がいなくても始められます。

  1. 道場のパソコンに Claude のアプリを入れる

    Mac か Windows のデスクトップアプリに Claude Code が入っています。スタッフみんなで使うなら、チーム用のプランにまとめると管理が楽です。

  2. 手元のExcelを1つ渡してみる

    「このファイルを見て、今月の合計を出して」から。答えが合っているか、最初の一回は自分でも確かめます。

  3. 毎月やる作業を1つ選んで型にする

    うまくいったら「今の手順をスキルにして」と頼む。翌月からは一言で同じ作業が回ります。

  4. 慣れたら予約システムや大会ページへ

    紫帯から先は、ログイン済みの画面を読ませる使い方に進みます。

料金やプランの内容は変わることがあります。契約前に公式サイトで確認してください。
