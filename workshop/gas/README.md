# ワークショップ予約の受付係をつなぐ手順

申込みページ（`/workshop/`）とキャンセルページ（`/workshop/cancel.html`）は、
Googleスプレッドシートに予約を書き込む「受付係」（Google Apps Script）とやりとりします。
一度つないでしまえば、あとの日時や定員の変更はスプレッドシートだけでできます。

## 1. スプレッドシートを用意する（10分）

1. Googleドライブで新しいスプレッドシートを作る（名前は「ワークショップ予約」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている中身を消して、`Code.gs` の中身をまるごと貼り付けて保存
4. 上の関数の選択欄で **setup** を選んで **実行**
   - 初回は「承認が必要です」と出るので、自分のアカウントで許可する
     （「このアプリは確認されていません」と出たら「詳細」→「〜に移動」）
5. スプレッドシートに戻ると **予約** と **枠** のシートができている

## 2. 日時と定員を入れる

**枠** シートに1行ずつ入れます。見本の3行は書き換えてください。

| 日時（表示） | 開始 | 定員 | 受付 |
|---|---|---|---|
| 7月18日14時30分〜 | 2027/07/18 14:30 | 6 | ○ |

- **日時（表示）**：申込みページにそのまま出る文字
- **開始**：キャンセル期限の計算と、開始後に自動で受付を締めるのに使う
- **定員**：この人数に達すると「満席」になり選べなくなる
- **受付**：`×` にするとその枠だけ受付停止（満席前に締めたいとき）

※ 予約が入ったあとで「日時（表示）」の文字を変えると、その枠の予約と結びつかなくなります。変えるときは予約シートの同じ列も直してください。

## 3. 選択肢や文面を変える（必要なら）

`Code.gs` の一番上の `CONFIG` を書き換えて保存します。

- `title`：ページとメールに出るイベント名
- `organizer`：メールの差出人名
- `notifyTo`：予約・キャンセルが入るたびに知らせるメールアドレス（事務局用）
- `cancelDeadlineHours`：開始の何時間前までページからキャンセルできるか（`0` で開始まで）
- `products` / `ages` / `sources`：制作物・年齢・知ったきっかけの選択肢

## 4. ウェブアプリとして公開する

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 種類の選択で **ウェブアプリ**
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

## 5. ページにURLを入れる

`workshop/config.js` の1行目を、コピーしたURLに書き換えます。

```js
window.WORKSHOP_API = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

これでデモ表示が消え、本番の受付になります。

## あとから `Code.gs` を直したとき

**デプロイ → デプロイを管理 → 鉛筆マーク → バージョン：新バージョン → デプロイ** で反映します。
（「新しいデプロイ」にするとURLが変わってしまうので注意）

## 予約シートの見かた

- **状態**：`予約中` / `キャンセル`。人数に数えるのは `予約中` だけ
- 事務局で手動キャンセルするときは、状態を `キャンセル` に書き換えれば枠が空く
- **キー** 列はキャンセル用リンクの合言葉なので、消したり人に見せたりしない
- 日時×制作物の集計は、ピボットテーブル（行：ご希望の日時、列：ご希望の制作物、フィルタ：状態＝予約中）で作れる

## 参加者がキャンセルするには

- 予約完了メールの **キャンセル用リンク** を押す
- または、キャンセルページで **予約番号＋メールアドレス** を入れて呼び出す

どちらも、期限（`cancelDeadlineHours`）を過ぎると「事務局へ直接ご連絡ください」と表示されます。
