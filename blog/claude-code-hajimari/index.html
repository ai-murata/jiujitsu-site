エンジニアじゃない私が、Claude Codeと「しつこく」付き合って1か月

2026.09.27　村田亜衣（マネージャー）

こんにちは。株式会社BUTTI ON LINEでマネージャーをしている村田亜衣です。

このブログでは、柔術の道場運営のことや良蔵さんのまわりのことを、マネージャーの目線でゆるく書いていきます。1本目は、ここ1か月ちょっとで私の仕事のやり方をガラッと変えた「Claude Code（クロードコード）」の話です。

インストールでつまずいて、チャットだけ使っていた

Claude Codeと聞くと「難しそう」「エンジニアの道具でしょ」と感じる人が多いみたいです。私も最初はまったく同じでした。

正直、インストールの時点でつまずきました。なので最初のうちは、普通のClaudeのチャットで質問するくらいしか使っていませんでした。

「絶対できるから、しつこくやらせて」

変わったきっかけは、濱田さんに5時間くらい教えてもらったことです。そのとき、いちばん心に残ったのがこのアドバイスでした。

AIは「できません」ってよく言ってくるけど、絶対できるから。しつこく「やって、やって」って戦うのがいいよ。

― 濱田さん

その言葉を信じて、最初の案件に5時間くらいかけてAIと格闘しました。「できません」と返されても、言い方を変えたり、別のやり方を頼んだりして、とにかく粘りました。

そうしたら、本当にできたんです。しかも終わるころには、「あ、こういうふうに言えばいいんだ」というコツがなんとなくつかめていました。

コツをつかんだら、やりたいことが止まらない

一度コツがつかめると、「じゃあこれもできる？」「あれもお願いしたい」と、やりたいことが次々に出てきました。

今では、毎月の請求書や振込リストのような事務作業、大会のライブ速報、動画やデザインづくりまで、マネージャー業務のかなりの部分をClaude Codeと一緒にやっています。このサイトのページも、ぜんぶClaude Codeで作りました。ひとつひとつの話は、これからこのブログで紹介していきますね。

濱田さんとの「近況報告会」

最近は濱田さんと会うたびに、お互いの近況を報告し合っています。

  • 「今回こんなの作ったよ」
  • 「営業の仕事をしている知り合いが、Claudeにデータを分析させて企画書まで作ったら、新しいお客さんが取れたらしいよ」

こういう話を聞くと、「じゃあ私の仕事ならこう使えるかも」とまたアイデアが湧いてきて、作ったものをもう一段よくしていけます。

もちろん悩みもあります。最近いちばん困っているのは、私が自分でパソコンを触っている最中に、Claudeに頼んでおいた作業が動き出して画面が切り替わってしまうこと。「ああっ」となって、どちらの作業も止まってしまいます。ほかにも、GitHub（作ったものを保存・公開する場所）のことや、MCP（AIとほかのサービスをつなぐ仕組み）のことなど、ちょこちょこ濱田さんに相談しながら進めています。

Claude Codeは、全然難しくない

この1か月ちょっとで実感したのは、Claude Codeは難しい道具ではないということです。専門知識がなくても、「こういうことがしたい」というアイデアさえあれば、どんどん形になっていきます。そして使えば使うほど、できることが増えていきます。

最近はClaude Codeの講座もたくさん見かけるようになりました。でも私がここで書きたいのは、「教える」ためのものではありません。

柔術道場を運営している方にも、普段の仕事や暮らしをちょっと楽にしたい方にも、「エンジニアじゃない人が、実際にこう使っているよ」という身近な一例を、同じ目線でお届けできたらと思っています。読んでくれた方の役に少しでも立てたら、それがいちばんうれしいです。

これからも思いついたときに、ゆるく語りに来ます。よろしくお願いします。
